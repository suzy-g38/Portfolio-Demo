# Stage 1: HTML, CSS & JavaScript

This branch (`01-html-css-js`) has two sibling folders:

- **[`starter/`](starter/)** — boilerplate with `TODO` comments.
  Students build here during the session.
- **[`completed/`](completed/)** — the finished, deploy-ready
  reference version.

Compare them any time — they're both checked out at once, right next
to each other, no branch switching needed within this stage.

## Quick start

```bash
cd starter
```
then see [`starter/README.md`](starter/README.md) for what to do, or
open [`completed/README.md`](completed/README.md) to see the finished
version and how it deploys.

Full workshop materials (student guide covering all three stages,
step by step): see [`STUDENT-GUIDE.md`](../../blob/main/STUDENT-GUIDE.md)
on the `main` branch.
