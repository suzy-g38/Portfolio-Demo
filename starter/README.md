# Portfolio Website — Starter

This is your starting point. The HTML structure is already there so we don't
waste workshop time typing boilerplate — your job during the session is to:

1. **Style it** in `css/style.css` (follow the `TODO` comments in that file).
2. **Add interactivity** in `js/script.js` (follow the `TODO` comments there).
3. **Make it yours** — swap in your own name, bio, skills, and email in
   `index.html`.

## How to run it

No build tools needed. Just open `index.html` in your browser
(double-click it, or in VS Code use the "Live Server" extension for
auto-refresh on save).

## Stuck?

The finished version lives one level up, at the root of this branch
